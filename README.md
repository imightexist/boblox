# boblox
(currently) unfinished roblox revival, no rcc support (yet, but i should say that trying to figure out rcc killed this project)
## features
- looks like 2016 roblox (with qol changes)
- robux & tix counters, theres no legit way to get robux
- inviting system (gives tix)
- account creation and sign in
- "admin" accounts with access to an "admin console" (you have to input thru f12 dev tools and it only accepts javascript thru eval)

## set up
```
npm i
node index.js
```
you'll need to replace `BOBLOX.collabai.lol` in all of the files with your domain, but the rest could be configured in config.json
